# 📊 Tweet Sentiment Analysis with Sentiment140

This project performs sentiment analysis on tweets using the [Sentiment140 dataset](https://www.kaggle.com/kazanova/sentiment140). The goal is to classify tweets into **Positive**, **Negative**, or **Neutral** sentiments using Python libraries.

---

## 🔧 Technologies Used

- Python 3.x  
- Pandas  
- Matplotlib / Seaborn  


---

## 📁 Dataset

- **Source**: [Kaggle - Sentiment140](https://www.kaggle.com/kazanova/sentiment140)  
- **Format**:
  - `0` = Negative
  - `2` = Neutral
  - `4` = Positive
